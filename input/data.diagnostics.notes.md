# 机制实验诊断配置笔记

当前 `data.diagnostics` 面向风强迫机制实验，保留基础状态、二维强迫、完整纬向动量收支和 GGL90 混合系数。归档控制实验的诊断配置保持原样。

## 输出清单

| 列表编号 | 文件前缀 | 当前用途 |
| --- | --- | --- |
| 1 | diag3d | 六个基础三维状态量 |
| 2 | diag2d | 七个二维状态及强迫量 |
| 3 | diag_mom_u | 九个纬向动量收支量；核实单位及闭合后再考虑精简 |
| 4 | diag_vel_moments | 已注释，保留原配置以便恢复 |
| 5 | diag_mix_ggl90 | 仅保留 GGL90ArU 和 GGL90Kr |

关闭速度二阶矩及速度积后，仍可使用 Um_Advec 分析总平流作用，但不能仅凭月平均速度恢复月内扰动动量通量。需要研究扰动输送时应恢复列表 4，并核实各诊断的网格位置与离散定义。

GGL90 内部量 GGL90TKE、GGL90Emn 暂停输出。需要研究闭合方案内部过程时，可将列表 5 恢复为：

```fortran
  fields(1:4,5) = 'GGL90ArU','GGL90Kr','GGL90TKE','GGL90Emn',
```

## 配置约定

- `fileName(n)` 指定列表 n 的输出文件前缀；编号保留空档，方便恢复已验证的列表。
- `fields(:,n)` 指定列表 n 的诊断名称，必须与当前可执行文件注册的名称一致。
- `frequency(n)=2629800.` 为固定 2629800 秒时间平均输出，并非逐自然月变长的平均周期。保留现有周期以保持比较一致。
- 当前没有设置子区域或层范围，仍输出原有完整空间范围。
- GGL90 与 KPP 的启用状态由 `data.pkg` 控制；更换方案时应同时切换对应诊断块，不能请求未注册的变量。
- `DIAG_STATIS_PARMS` 保持 momKE、ETAN、RHOAnoma，`stat_freq=-864000.` 表示每十天一次瞬时统计，用于运行监控。

精简后活动三维变量由 25 个减为 17 个；在相同网格和输出频率下，这部分记录量约减少 32%。实际总存储降幅受其他输出影响。
