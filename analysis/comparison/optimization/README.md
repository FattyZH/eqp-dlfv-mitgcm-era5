# 控制实验优化测试方案

2026-10-08。验证基准：用户已确认与观测一致的 CMEMS；首要位置为 142°E、0°及海脊以西。此目录保存测试方案与诊断模板。

诊断字段解释、参数速查、KPP替代配置和区域统计备用配置集中在[诊断配置笔记](../../../input/data.diagnostics.notes.md)；`input/data.diagnostics` 只保留简短分组注释。

按后续请求，`input/data.diagnostics` 已配置五类输出：`diag3d`（基础三维场）、`diag2d`（二维与表面强迫）、`diag_mom_u`（纬向动量预算）、`diag_vel_moments`（速度二阶矩与乘积）、`diag_mix_ggl90`（GGL90混合状态）。均保持2629800秒平均，diagSt保留原有三个变量并增加三维速度和温盐统计。速度积流额外保存`UE_VEL_C`、`VN_VEL_C`，以便与`UV_VEL_C`在相同格点上计算协方差。40层配置合计1007个诊断层槽，`code/DIAGNOSTICS_SIZE.h`已改为`numDiags=40*Nr`；尚未重新编译或启动模拟。现有build头文件与已编译可执行文件仍是旧容量，运行前必须更新编译。切换KPP时应替换第5个混合输出流的名称与字段，不能同时启用两方案专属诊断。

## 二维诊断的当前选择

第2流目前保存7个二维场，替代原来的测试用热通量分量和蒸发输出；频率与文件名保持不变。

| 字段 | 选择目的 |
|---|---|
| `ETAN` | 海面高度，用于盆地调整及表面压力响应 |
| `PHIBOT` | 海底压力位势异常，辅助检查深层/整柱压力响应；单位m²/s²，不是Pa |
| `oceTAUX`、`oceTAUY` | 海洋动量网格上的表面应力，用于风驱与应力旋度；须处理U/V交错网格 |
| `MXLDEPTH` | 通用混合层深度诊断，检查方案改变是否首先改变上层；不等同于KPP边界层深度 |
| `TFLUX` | 与热含量变化对应的总热通量，替代只看感热/潜热分量；正值加热 |
| `oceFWflx` | 净表面淡水通量，替代只看蒸发；kg/m²/s，正值进入海洋 |

`PHIBOT` 与三维 `PHIHYD`、动量压力项联合分析，不能用海底压力单独替代各深度的压力梯度。`oceTAUX/Y` 比EXF中间应力更适合与海洋动量预算配合；EXF应力位于不同网格位置，不能不经插值直接逐点比较。当前没有同时保存两套应力，避免冗余。

原第2流的字段保留为备用记录：

```fortran
# 原测试设置，当前未启用
# fields(1:5,2) = 'ETAN','EXFtaux','EXFevap','EXFhs','EXFhl',
```

若需要检查风速过滤、bulk或相对风处理，另加 `EXFuwind`、`EXFvwind`，必要时加 `EXFurelw`、`EXFvrelw`、`EXFtaux`、`EXFtauy`。分析热通量分量时再恢复 `EXFhs/EXFhl` 等；分析盐收支可另加 `SFLUX`。底摩擦专题再考虑 `botTauX/Y`。这些是按问题选用的备用字段，不全部加入默认流。

## 运行健康统计与旧控制实验对比

`DIAG_STATIS_PARMS` 使用全域统计，保留原有 `momKE、ETAN、RHOAnoma` 的顺序、`diagSt` 文件名前缀和10天瞬时快照频率，增加 `UVEL、VVEL、WVEL、THETA、SALT`。未修改 `stat_phase`，与旧配置保持相同采样时刻。负频率默认相位为半个周期，时间起点为0时通常在第5、15、25天等采样，而不是第10、20天。统计输出含空间均值、空间标准差、最小值、最大值；三维场还可按层检查，空间标准差不是时间波动振幅。

| 字段 | 运行检查重点 |
|---|---|
| `momKE` | 均值及最大值是否突然持续增长；与旧控制实验比较整体动能水平 |
| `ETAN` | 均值漂移、标准差及极值异常；区域开放边界下均值变化须结合质量收支解释 |
| `RHOAnoma` | 保留旧实验可比指标，检查密度异常及分层变化 |
| `UVEL、VVEL` | 极值定位流速尖峰，标准差辅助检查环流强度变化 |
| `WVEL` | 极值突增提示垂向速度异常，结合地形、边界和时间步检查 |
| `THETA、SALT` | 极值检查异常温盐，逐层均值检查缓慢漂移，尤其深层 |

这些变量已在控制实验可用诊断列表中确认。7个40层三维场加1个二维场共281个统计层槽，现有400个统计层槽足够，本次无需再扩大统计数组。U/V位于交错网格，直接比较各自统计即可。比较旧实验时应对齐模拟日期、季节和重启动后的调整阶段，优先判断异常突变、持续增长和明显漂移，不把方案导致的正常动能差异直接判为不稳定，也不设脱离本区域背景的统一温盐阈值。

10天快照适合留存长期健康记录，可能漏掉短时异常。当前 `input/data` 的 `monitorFreq=2629800.` 约为月频；新测试建议另将其改为 `86400.`（每天STDOUT监控），必要时短测试更频繁。本次只调整诊断配置，未修改该运行参数。全域统计不足以评价142°E深层年际输运是否改善，仍须使用断面及目标深度层的比较指标；需要区域监控时再启用区域掩膜。

## 使用已有配对，避免重复整段积分

`260915_ctrl1`：GGL90；`260916_ctrl_kpp`：KPP。两者 data、data.exf、data.obcs 文件相同，主 pickup.clim_r4_1 链接到同一文件；exf/obcs 链接也相同。可用它们作为现有方案对照，比 `260821_ctrl` 与 KPP 更公平。两个可执行文件不同，最终严谨对照仍需核对编译选项、源版本与方案专属重启动状态；优先用同一包含两方案的可执行文件。

142°E、0°、共同期下，整层 2–8 年流速代理指标为 GGL90 r=0.774、振幅比=0.711、平均偏差=-2.11 cm/s；KPP r=0.885、振幅比=0.651、平均偏差=-4.16 cm/s。1500–2000 m 的平均偏差为 -5.37 与 -10.32 cm/s。KPP 提高部分相关性，却没有解决弱振幅和背景流偏差，不宜仅按整层相关性取代控制方案。

## 先做诊断基线

以 `260915_ctrl1` 配置为主基线，在新目录中增加诊断，保持其他设置一致。基线运行是后续新试验的比较对象，避免新增诊断或更换可执行文件的影响混入参数变化。KPP 可作诊断辅助对照。

模板 `data.diagnostics.ggl90` 保留 diag3d/diag2d，并增加月平均动量预算、混合及速度乘积。KPP 运行将 diag_mix 改为：

```fortran
fields(1:3,5) = 'KPPviscA','KPPdiffT','KPPdiffS',
```

此目录的精简模板约需927个诊断层槽；原可执行文件容量为`20*Nr=800`，不能直接使用。源码容量已改为`40*Nr`，还需重新编译包含所需方案的可执行文件。模板与当前input使用相同的8变量统计配置，占用独立统计容量281个层槽，小于`diagSt_size=10*Nr=400`。TOTUTEND 是 m/s/day，Um_* 是 m/s²；Um_hDis4 用于分解耗散，不能再与包含它的总耗散重复相加。

当前 720×192×40 网格，模板 23 个三维场约 0.51 GB/月，约 6.1 GB/年（十进制、float32，未计额外输出）；只在必要筛选窗口启用完整预算，暂不增加全域五天输出。线上月平均乘积保留月内协方差信息，但不能单独隔离 20–90 天季节内频带，后续机制试验再增加高频数据。

## 第一轮参数筛选，按诊断决定分支

现有参数：GGL90ck=0.1、GGL90ceps=0.7、GGL90m2=3.75、mxlMaxFlag=1；STDOUT 确认 GGL90TKEmin=1e-11、TKEsurfMin=1e-4、TKEbottom=1e-11；viscAr=diffKrT=diffKrS=1e-5。data.ggl90 的注释 TKEmin=1e-8 不是当前生效值。

如果目标层 GGL90ArU/GGL90Kr 明显高于背景下限且预算提示垂向耗散重要，优先三个新测试：

| 试验建议名 | 唯一参数变化 | 目的 |
|---|---|---|
| G0_diag | 不改物理参数，只增诊断 | 共同基线 |
| G1_ck07 | data.ggl90：GGL90ck=0.07 | 较弱的湍流交换系数敏感性 |
| G2_ck14 | data.ggl90：GGL90ck=0.14 | 较强的湍流交换系数敏感性 |

这些数值是探索扰动，不是经过校准的最优值。ck 改变粘性及相关扩散，并反馈 TKE/分层，实际系数不一定按比例变化。不能将 G1/G2 简称为纯动量耗散干预。保留 ceps、m2、mxlMaxFlag、TKEmin 等其他参数不变。

如果深层系数主要贴在背景下限，先测试 `data/PARM01` 的 viscAr=5e-6 与 2e-5（对照 1e-5），保持 diffKrT/S 不变，检查垂向动量下限敏感性。若证据指向分层扩散，再单独测试 diffKrT/S 的同倍率变化；不与 viscAr 同时改变以便区分作用。

不建议首先把 TKEmin 改为 1e-8：这是相对于生效值提高 1000 倍。先看 GGL90Emn 对应的下限补能是否重要。也不建议同时修改 ck、ceps、m2 和混合长度算法。

## 第二轮，仅在第一轮证据不足时

- 若水平耗散重要，分别试 viscA4=1e10 与 4e10，基线2e10。检查格点噪声与平均态，不能因振幅变大就判定改善。
- 若垂向结构失配持续，优先做 800–3000 m 加密（约50–100m，平滑过渡）的网格敏感性。需重新映射全套初始/边界场及包状态，不可直接复用旧40层pickup；固定水平地形，保持共同深度上的公平比较。
- 对目标海脊检查关键通道、鞍部和湿面积后再做地形敏感性。改变地形会同时改变几何输运面积与动力响应，应分开诊断。
- 在有边界影响证据时才试海绵时间尺度；RBCS实际关闭，第一轮不启用东部恢复或改变边界强迫。

## 时段与重启动

短筛选建议从相同现有 checkpoint 运行约5–10年，包含2015–2016事件，分析调整后的均值、分层和预算。现有 ctrl1 的 pickup.0000499662.meta 对应2009-12-31；采用该点前须同时检查日历、nIter0/startTime、包pickup与恢复历史，不能只改pickupSuff。

保留从方案变化开始的完整输出，通过滚动均值判断调整；不要默认固定三年已完成深层调整。短试验可排除明显不合理参数，但不足以可靠评价2–8年频带全部周期，也不能使用两端各裁剪三年后剩余很短的记录来选择最终方案。

最终入选的1–2组需按原始多年覆盖做长积分，与独立验证时段及长期CMEMS对照。目标若是各方案平衡态，还需分别有充分spinup；共同状态分支用于初步受控响应，不能代替平衡态比较。

## 选择新控制实验的标准

同时检查142°E观测深度、海脊以西的纬度—深度断面和真实Sv输运；现有厚度平均U只是代理。重点为：

1. 1000–2000m平均西向偏差减小，不能靠不同深度抵消。
2. 年际标准差比向1靠近；相关性、事件符号与相位不明显恶化。
3. N²、温盐、流核深度和垂向剪切改善；无长期漂移或格点噪声。
4. 压力/平流/耗散预算能解释变化；参数在邻近区域及独立时段也有效。

固定观测/CMEMS基准，以多个指标筛选；先校准一部分年份，再用留出年份检验。不要只用整层相关性或CEOF1贡献率排序。

## 参数依据

本地运行 STDOUT、build/ggl90_calc.f 确认 GGL90ck 参与混合长度×sqrt(TKE)的系数，并存在背景系数下限；不是独立的深层阻尼旋钮。另见[官方参数源代码](https://lxr.mitgcm.org/lxr2/source/MITgcm/pkg/ggl90/ggl90_readparms.F)及[GGL90参数说明](https://mitgcm.org/public/r2_manual/final/code_reference/vdb/code/1293.htm)。
